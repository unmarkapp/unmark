## Detailed description

```
Unmark for Gemini removes the visible sparkle watermark from images you generate on Gemini and Google Flow — without leaving the tab.

HOW IT WORKS
1. Install Unmark for Gemini
2. Sign in at unmark.ink so jobs use your Cloud credits and appear in Library
3. Generate on Gemini or Google Flow as usual
4. Queue prompts or capture the latest image — Unmark cleans the sparkle and downloads a clean PNG

WHAT THE EXTENSION DOES
• Auto-remove Gemini sparkle watermarks on stills
• Queue multiple generations and clean in batch
• Save cleaned images to your Unmark Library (Cloud)

FULL PRODUCT ON THE WEB (unmark.ink)
• Instant mode — free single-image cleanup in the browser (no account)
• Video watermark removal — Veo, Google Flow, Gemini clips
• Background removal — transparent PNG cutouts
• Library, bulk jobs, and Google Drive export

Unmark is built for Google AI exports (Gemini, Veo, Flow, Imagen, Nano Banana) — not a generic logo eraser.

Privacy: image jobs you run through the extension use your Unmark Cloud account. See https://www.unmark.ink/privacy

Get started: https://www.unmark.ink/product
```
